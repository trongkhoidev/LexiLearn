### 4. Teacher Flows (Frontend UI)

#### 4.1. Classrooms

- ✅ **Implemented**
  - `Classrooms` page (`src/pages/Classrooms.js`):
    - Shows list of classrooms (via `db.classrooms.listByTeacher`).
    - Simple creation flow (prompt-based) for new class.
    - Integrated route `/classes` and sidebar item "Classrooms".
  - `ClassroomDetail` page (`src/pages/ClassroomDetail.js`):
    - Shows basic class info (title, description).
    - Shows student list (via `db.classroomMembers.listByClassroom`).
    - Add student by raw `student_id` (UUID prompt).
    - Shows basic assignments list (via `db.assignments.listByClassroom`).
    - Create simple assignment (title + module + `status = 'published'`).
    - NEW: quick action to create assignment sourced from Cambridge test.
- ⏳ **Missing / To improve**
  - No nice UI to search/select students (currently paste UUID).
  - No inline edit/archive class.
  - No per-student progress summary in class detail (yet).

#### 4.2. Assignments (including Cambridge)

- ✅ **Implemented (basic)**
  - `db.assignments` helpers mapped to Supabase.
  - In `ClassroomDetail`:
    - "New Assignment" prompt (manual, module string).
    - "Assign Cambridge Test" prompt:
      - Teacher enters `test_id` (from `tests` table).
      - Creates assignment with:
        - `source_type = 'cambridge_library'`
        - `source_ref_id = test_id`
      - Automatically creates `assignment_targets` for all current class members.
- ⏳ **Missing / To implement**
  - Proper UI to browse Cambridge books/tests/sections:
    - From class detail: pick **Book → Test → Module (Reading)** visually.
    - Option to assign single Passage (`sections.id`) instead of full test.
  - Assignment detail page:
    - See who has submitted / not submitted.
    - Open a student's submission and grade.
  - Scheduling:
    - `due_at` picker, `time_limit_minutes`, allow multiple attempts.

#### 4.3. Submissions & Grading

- ⏳ **Not implemented in UI yet**
  - No page for Teacher to: open assignment, see list of `submissions`, review answers.
  - No grading UI for Writing/Speaking; only DB schema + helpers exist.

#### 4.4. Materials / Folder Tree

- ⏳ **Not implemented in UI yet**
  - Data layer exists (`material_folders`, `materials`), but no screens yet for:
    - Teacher to create folders/band trees (Vocabulary, Grammar, Skills).
